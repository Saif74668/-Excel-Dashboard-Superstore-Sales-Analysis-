# 📊 Superstore Sales Dashboard (Excel)

## Project Overview

The **Superstore Sales Dashboard** is an interactive business intelligence dashboard built in **Microsoft Excel** to analyze sales performance, profit trends, customer segments, and regional performance using real-world superstore sales data.

The objective of this project was to transform raw sales data into meaningful business insights through interactive visualizations and dynamic reporting. This dashboard enables users to explore sales trends, identify top-performing categories, and evaluate profitability across different business dimensions.

## Key Business Metrics

* **Total Sales:** £429,653.15
* **Total Profit:** £665.97
* **Profit Percentage:** 0.89%
* **Top Customer Segment:** Consumer
* **Top Product Category:** Office Supplies

## Features & Insights

This dashboard provides detailed analysis including:

### 📈 Sales Performance Analysis

* Monthly sales trends to identify peak-performing periods
* Quantity sold analysis across months
* Quarterly and yearly performance comparisons

### 🛒 Product & Category Insights

* Identification of top-performing product categories
* Analysis of high-selling products such as **Binders, Phones, and Chairs**
* Category-level sales comparison

### 👥 Customer Segment Analysis

* Revenue contribution by customer segment
* Consumer segment performance analysis
* Comparative segment visualization using treemap and charts

### 🚚 Shipping & Regional Analysis

* Shipping mode analysis with **Standard Class** dominating deliveries
* Regional comparison across **Central, East, South, and West**
* Sales and performance tracking by region
